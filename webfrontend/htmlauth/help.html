Samsung Frame TV Plugin – Help

Overview

This plugin provides two-way local integration between a Samsung The Frame TV and Loxone via MQTT. No cloud or SmartThings account is required — all communication is direct over your local network.

Version 1.1 adds support for multiple TVs. One TV can be marked as the primary TV for the base MQTT topics, while each configured TV also gets its own device-specific topics.

Initial Setup

  1. In General Configuration, keep or adjust the base MQTT topics and polling settings.
  2. In TV Configuration, configure one or more TVs. For each TV, enter the IP address and optionally the MAC address. The MAC address is discovered automatically on save when possible.
  3. Select which TV should be the primary TV. That TV keeps the original base MQTT topics.
  4. Make sure the TV is powered on and displaying a picture.
  5. Click Start Pairing on the TV you want to pair. A popup will appear on that TV — accept it within 30 seconds. Each TV stores its own pairing token and reuses it automatically.
  6. The monitor daemon starts automatically when LoxBerry boots. After pairing, it will begin publishing TV state to MQTT.

TV States

StateMeaning
offTV is in standby
artTV is on and Art Mode is active
onTV is on and showing normal content

The primary TV publishes to the configured base state topic and to its own device topic. Additional TVs publish to <state topic>/<device_id>. Device availability is published to <state topic>/availability/<device_id> with values online / offline.

MQTT Commands

Publish any of the following payloads to the primary command topic or a device-specific command topic:

PayloadAction
power_onWake TV from standby (WebSocket or Wake-on-LAN)
power_offHold power button 3 s — powers off the TV
art_onEnable Art Mode
art_offDisable Art Mode
key_KEY_MUTESend the MUTE key
key_KEY_VOLUPSend the VOLUME UP key
key_KEY_VOLDOWNSend the VOLUME DOWN key
key_XXXXSend any raw Samsung remote key

Topic layout:
<cmd topic> → primary TV
<cmd topic>/<device_id> → one specific TV
<cmd topic>/all → all enabled TVs

Loxone Integration

In Loxone Config, use a Virtual Input (text input) listening on the state topic to react to TV state changes. For extra TVs, use the device-specific state topic. Use a Virtual Output publishing to the command topic you want to target.

Troubleshooting

  • Pairing fails / no popup on TV: Ensure developer mode is enabled on the TV (Settings → Support → Device Care → Developer Mode).
  • Art mode not detected: Art mode API requires a 2024 or later firmware. Update the TV firmware and retry.
  • State stuck at "unknown": The daemon may not be running. Check the log at /opt/loxberry/log/plugins/samsungframe/monitor.log.
  • One TV works but another does not: Confirm the extra TV has its own IP address, topic suffix, and pairing token. Pair each TV separately.
  • Wake-on-LAN not working: Ensure the MAC address is correct and that the TV is on wired Ethernet.
